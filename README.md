一个运行在 [Tampermonkey](https://www.tampermonkey.net/) 上的用户脚本，面向国家开放大学学习平台 `lms.ouchn.cn`，把「读题 → AI 作答 → 逐题填入 → 全对交卷 → 读成绩」这条链路自动化，用于**技术学习**与**题目自测**。

## ✨ 功能特性

| 能力 | 说明 |
|---|---|
| **全自动一条龙** | 进入答题页即开跑，读题 → 请求 AI → 逐题填入 → 校验 → 交卷 → 读分，无需人工干预 |
| **多题型支持** | 单选、多选、判断、填空（contenteditable）、**完形填空（下拉选择）**、**匹配 / 拖拽题** |
| **100% 命中才交卷** | 只有全部题目都确认写入成功才自动提交；有任何一题没写进去就**留着不交**，绝不上交半份答卷 |
| **未过自动重答** | 交卷后读分，未达线则带着这次的结果重新作答（默认最多 3 次） |
| **一键全部考试** | 课程页批量模式：只跑「测试 \| 形考任务」系列里**未完成**的场次，逐场跑完自动下一场 |
| **刷新/跳转可续跑** | 平台会强制跳转刷新，脚本把进度存本地，重载后自动接上，不会从头再来 |
| **零等待入场** | 答题页一渲染就开跑，不用手动点按钮等倒计时 |
| **急停按钮** | 一键掐掉正在飞行的 AI 请求并复位，不留半成品状态 |
| **诊断报告** | 面板内一键生成诊断信息（页面结构、状态、日志），方便提 Issue |
| **面板可拖动且位置常驻** | 拖到哪就记住哪，刷新、重绘、换页都回到原位 |
| **密钥本地化** | API 密钥只存在 Tampermonkey 私有存储（`GM_setValue`），网页 JS 读不到，代码里不含任何密钥 |

## 📦 安装

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Edge / Chrome 均可）。
2. **一键安装**（点开会自动弹出 Tampermonkey 安装页）：

   ```
   https://raw.githubusercontent.com/wsQvQ/ouchn-ai-auto-answer/main/ouchn-ai-auto-answer.user.js
   ```

   想手动装也行：打开仓库里的 `ouchn-ai-auto-answer.user.js` → 点右上角 **Raw**；或复制全部代码 → Tampermonkey「添加新脚本」→ 粘贴 → `Ctrl+S`。
3. 打开 `https://lms.ouchn.cn/`，右侧会出现脚本面板。

> 脚本在 Tampermonkey 里显示的名字是 `@name`（国开 AI 自动答题），与仓库文件名无关。

> 脚本 `@match` 只匹配 `https://lms.ouchn.cn/*`，不会在其他网站运行。

## 🚀 快速开始（3 步）

1. 点面板右上角 **⚙**，填三样东西：
   - **接口**：OpenAI 兼容地址，一般以 `/v1` 结尾，例如 `https://api.deepseek.com/v1`
   - **密钥**：你自己的 API Key（只存本机）
   - **模型**：模型名，例如 `deepseek-chat`
   点 **测试连接** 确认通。
2. 打开要做的考试 / 形考任务（课程页可用 **一键全部考试** 批量跑）。
3. 坐下看着就行。面板会实时显示「当前步骤 / 答题进度 / AI 思考状态」，随时可以 **急停**。

## 🧠 工作原理（技术概览）

平台前端是 **AngularJS**，答案不是"填到 DOM 里"就算数，而是必须写进 **Angular 的 scope 模型**并触发平台自己的登记钩子。脚本的核心是一套"**模型优先、DOM 兜底、写后校验**"的写入策略：

```
选择题   → 写 scope.answeredOption + 触发 ng-change 登记 + $apply
填空题   → contenteditable 输入 + Angular 模型同步 + 读回校验
完形填空 → blank.answeredOption = String(选项id)      ← 必须是字符串
           + 调 ng-change="onChangeSubmission(blank)"
           + $apply()，并手工同步下拉外观（绝不派发 input/change）
匹配拖拽 → 写 sub_subjects[].answeredOption/answer_number/note + $parent 链登记
```

几个踩过坑后固定下来的要点：

- **写完必须读回校验**：只改 DOM 看起来"填上了"，但平台并不认；脚本按 Angular 模型读回确认，校验失败才走 DOM 兜底路径。
- **完形填空绝不派发 `input`/`change` 事件**：会触发 Angular 反读 DOM 值，把刚写好的答案冲掉。
- **答案必须是选项 id 的字符串**：写成对象会让前端以为已作答、进度条也动，但后端保存时会报「提交数据格式异常」，直接毁掉整场提交。
- **交卷前逐题二次校验**：命中数不足 100% 就不提交，避免"交了但不算分"。

## 🛡️ 安全设计

- **不交半份卷**：`100% 命中` 是自动交卷的唯一条件；部分写入成功也绝不提交。
- **急停是真急停**：不仅复位状态，还会 `abort()` 掉正在进行的 AI 请求。
- **不猜答案**：AI 返回无法解析时按失败处理并重试，不会硬填一个凑数。
- **密钥不出本机**：代码内无密钥；设置项存于 Tampermonkey 私有存储。

## ❓ 常见问题

<details>
<summary><b>面板一直显示"AI 思考中"，很久没反应？</b></summary>
推理型模型在长卷子（40+ 题）下首轮可能耗时 1–3 分钟，属正常范围。脚本对"要答案"的正式请求带了自动回炉（加大 token 重发）。持续异常请点面板里的诊断，把报告发到 Issue。
</details>

<details>
<summary><b>为什么进度显示 0/46，但 AI 明明在跑？</b></summary>
「答题进度 n/N」是<b>平台</b>的计数：一道完形填空的所有空都答完才计 1 题。脚本自己的填入进度在面板下方单独显示。
</details>

<details>
<summary><b>脚本会不会把我答了一半的卷子交上去？</b></summary>
不会。自动交卷只在全部题目校验通过后触发；任何一题失败就停在原地等你处理。
</details>

<details>
<summary><b>提示"提交数据格式异常"怎么办？</b></summary>
这是平台侧的保存校验失败，通常来自异常的表单值。重新进入答题页再跑一次即可；仍复现请附诊断报告提 Issue。
</details>

<details>
<summary><b>面板跑到屏幕外了 / 想换个位置？</b></summary>
按住面板顶部拖动即可，松手后位置会被记住（v1.7.19+），刷新和重绘都不会弹回角落。位置超界会自动夹回可见区域。
</details>
